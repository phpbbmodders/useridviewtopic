# User ID in Viewtopic

[![Tests](https://github.com/phpbbmodders/useridviewtopic/actions/workflows/tests.yml/badge.svg)](https://github.com/phpbbmodders/useridviewtopic/actions/workflows/tests.yml) [![Lint](https://github.com/phpbbmodders/useridviewtopic/actions/workflows/lint.yml/badge.svg)](https://github.com/phpbbmodders/useridviewtopic/actions/workflows/lint.yml)

Shows each poster's user ID next to their posts.

## Features

- The poster's user ID appears under their rank on topic pages.
- On/off switch: **ACP → General → Load settings → Display user id on topic pages**.

## Requirements

- phpBB 3.3.19 or later
- PHP 8.2 or later

## Installation

1. Copy the extension to `/ext/phpbbmodders/useridviewtopic`
2. In the Administration Control Panel, go to **Customise → Manage extensions**
3. Enable the **User ID in Viewtopic** extension
